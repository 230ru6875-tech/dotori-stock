사이트 정보

오늘의 주식은 국내주식과 미국주식 관심종목을 한 곳에 모아 비교할 수 있도록 만든 공개 주식 정보 리포트 사이트입니다. 사용자가 입력한 관심종목과 운영 데이터 기준 후보를 함께 보면서 현재가, 이평선, 급등락, 뉴스, 섹터 흐름, 심층분석 메모를 빠르게 확인할 수 있도록 구성했습니다.

운영 목적

이 사이트의 목적은 투자 판단에 필요한 공개 정보를 정리해 보여주는 것입니다. 가격만 보고 진입하거나 한 줄 점수만 보고 결론을 내리지 않도록, 어떤 종목이 왜 후보가 되었는지와 무엇을 더 확인해야 하는지를 같이 제시하는 방향을 택하고 있습니다.

제공하는 정보

  • 관심종목 현재가와 구입가 대비 흐름
  • 국내장과 미국장 종목스캐너 후보
  • 급등락, 이평선, 거래량, 기술적 단서
  • 모닝노트, 섹터오버뷰, 심층분석 메모
  • 공개 가능한 종목 리포트와 뉴스 목록

데이터 범위와 한계

공개 대시보드는 운영자가 수집해 공개 저장소에 반영한 데이터와 사용자가 브라우저에 입력한 관심종목을 함께 사용합니다. 실시간 체결 시스템이 아니므로 지연, 누락, 오류가 있을 수 있으며, 종목별로 재무지표나 보조지표 수집이 늦을 수 있습니다. 데이터가 비어 있거나 확인이 더 필요한 경우에는 부족한 항목을 그대로 표시합니다.

투자 판단 원칙

오늘의 주식은 투자 참고 정보를 제공하지만, 특정 종목의 매수나 매도를 권유하지 않습니다. 관찰, 주의, 대기, 강한 매수 같은 문구는 데이터 흐름을 빠르게 읽기 위한 표시일 뿐이며, 실제 주문 전에는 증권사 현재가, 거래소 공시, 기업 실적, 환율, 시장 전체 흐름을 사용자가 직접 확인해야 합니다.

공개 운영 기준

사이트의 정적 문서와 종목 리포트는 검색엔진과 일반 방문자가 읽을 수 있도록 공개되며, 개인 계좌 보유내역이나 개인 주문 정보는 웹 공개 화면에 직접 노출하지 않는 것을 원칙으로 합니다. 브라우저에 저장되는 관심종목 정보는 사용자의 로컬 저장소 기준으로 동작합니다.
