사이트 정보

오늘의 주식은 국내주식과 미국주식 데이터를 한곳에 모아 비교하기 위한 공개 정보 사이트입니다. 관심종목, 종목스캐너, 성장주 후보, 급등락, 이평선, 뉴스, 심층분석 메모를 연결해 보여주지만, 이 사이트 자체가 증권사 주문 화면이나 투자 자문 서비스는 아닙니다.

운영 목적

이 사이트의 목적은 “무엇을 사라”가 아니라 “무엇을 다시 확인해야 하는가”를 정리하는 데 있습니다. 가격과 점수만 보여주면 해석 부담이 이용자에게 그대로 넘어가기 때문에, 가능한 한 근거 문장과 부족한 항목을 함께 남기는 방향으로 운영합니다.

콘텐츠 작성 기준

오늘의 주식에 실리는 정적 설명 문서와 종목 리포트 해설 문장은 운영 측에서 직접 정리한 텍스트를 중심으로 작성합니다. 외부 데이터, 외부 뉴스, 공개 시장 가격은 출처를 바탕으로 재구성해 보여주며, 원문을 그대로 복제한 페이지를 늘리는 방식은 피합니다. 같은 내용을 여러 페이지에 반복하지 않도록 설명 문구와 요약 구조도 계속 조정합니다.

데이터 범위와 한계

공개 대시보드에는 운영 시스템에서 수집한 공개 데이터와 브라우저에 저장된 관심종목 정보가 함께 반영될 수 있습니다. 다만 모든 종목에 대해 항상 가치지표와 기술지표가 모두 채워지는 것은 아닙니다. 확보되지 않은 값은 추정으로 채우지 않고 비워 두거나 확인 필요로 표시합니다. 이것은 품질이 낮은 자동 채우기를 피하기 위한 기준입니다.

인간 검토와 책임 구분

오늘의 주식은 자동 수집과 자동 정리를 활용하지만, 최종 투자 판단은 이용자가 직접 해야 합니다. 특히 금융 정보는 시차, 오류, 누락 가능성이 있기 때문에 실제 주문 전에는 반드시 증권사 화면, 공시, 실적 발표 자료, 당일 거래량과 체결 흐름을 다시 확인해야 합니다. 이 사이트의 문구는 매수나 매도 지시가 아니라 점검을 돕기 위한 참고 표현입니다.

공개 원칙

공개 웹에서는 개인 계좌의 민감한 정보, 개인 보유 수량, 비공개 인증 정보, 주문 비밀번호, API 비밀키를 노출하지 않습니다. 공개 가능한 종목 요약과 설명, 일반 시장 데이터, 뉴스 링크, 교육성 문서만 웹 화면에 반영하는 것을 원칙으로 합니다.

누가 읽으면 좋은가

관심종목을 여러 곳에서 흩어 보지 않고 한 화면에서 비교하려는 이용자, 가격 신호와 뉴스 단서를 함께 보고 싶은 이용자, 가치지표와 기술지표가 모두 충족되는지 차분히 점검하려는 이용자에게 맞는 사이트입니다. 반대로 즉시 주문 지시나 수익 보장을 기대하는 용도에는 맞지 않습니다.
